# Merger Rate Deconvolution

## Overview

This project reconstructs BBH progenitor formation rates from observed merger rates using delay time distribution models. It implements numerical deconvolution techniques to explore which delay time distributions are physically allowed under observational constraints. This is companion code to the paper "Forbidden Formation Histories: The Binary Black Hole Merger Rate Disfavours Long Delay Times".

## Dependencies

* numpy
* matplotlib
* astropy
* jax
* scipy
